# Broadway Final Projects

This repository contains four web development projects created as part of my final web development assignment.

## Projects

### 1. TechSpree — E-commerce Website
A modern e-commerce website for browsing technology products, viewing product details and managing a shopping cart.

### 2. Vantrex Technologies — Corporate Website
A professional corporate website for a fictional technology company offering software, AI, cloud and digital solutions.

### 3. PULSE24 — News Portal
A modern news portal website featuring news categories, latest articles, article details and contact information.

### 4. Himalaya Horizons — Travel & Tours Website
A Nepal-focused travel and tourism website featuring destinations, tour packages, tour details and travel inquiry forms.

## Technologies Used

- React
- Vite
- JavaScript
- HTML5
- CSS3
- React Router
