# Broadway Final Projects

This repository contains four complete web development projects created as part of my final web development assignment at Broadway Infosys. The projects were developed using modern front-end technologies with a focus on responsive design, user-friendly interfaces, reusable React components, navigation, interactive features and clean project structure.

The repository includes an E-commerce Website, Corporate Website, News Portal Website and Travel & Tours Website. Each project has its own separate folder and demonstrates a different type of real-world website.

## Projects

### 1. TechSpree — E-commerce Website

**TechSpree** is a modern technology-focused e-commerce website designed for browsing and exploring electronic products.

The website includes product categories, product listings, product details, search functionality, shopping cart functionality and multiple pages for users to explore the store.

**Main Features:**
- Home page
- Product shop
- Product categories
- Product details
- Product search
- Shopping cart
- About Us page
- Contact page
- Responsive navigation
- Interactive product cards

**Technologies:**
- React
- Vite
- JavaScript
- HTML5
- CSS3
- React Router

### 2. Vantrex Technologies — Corporate Website

**Vantrex Technologies** is a professional corporate website created for a fictional technology company. The website presents the company, its services, team, culture and contact information through a modern corporate interface.

The design focuses on a professional technology-oriented appearance with a dark visual theme and modern layouts.

**Main Features:**
- Corporate homepage
- Company information
- Technology services
- Artificial Intelligence services
- Software development services
- Web and app development
- Cloud solutions
- Cybersecurity
- Digital transformation
- Team section
- Contact section
- Responsive design

**Technologies:**
- React
- Vite
- JavaScript
- HTML5
- CSS3
- React Router

### 3. Nepal Darpan — News Portal Website

**Nepal Darpan** is a modern news portal designed to provide users with organized news content across different categories.

The website includes multiple news categories, latest articles, individual article pages and dynamic category-based article filtering.

**Main Features:**

### 4. Himalaya Horizons — Travel & Tours Website

**Himalaya Horizons** is a Nepal-focused travel and tourism website designed to showcase destinations and tour packages across Nepal.

The website allows users to explore different destinations, view detailed tour information and submit travel inquiries through an interactive contact form.

**Main Features:**
- Travel homepage
- Nepal destinations
- Tour packages
- Tour details
- Everest Base Camp Trek
- Mustang Adventure
- Kathmandu Heritage Tour
- Pokhara Escape
- Illam
- Badimalika
- Travel inquiry form
- Destination selection
- Inquiry confirmation
- About page
- Contact page
- Responsive design

## Technologies Used

- **React.js** — Component-based user interface development
- **Vite** — Modern front-end development and build tool
- **JavaScript** — Application functionality and interactivity
- **HTML5** — Website structure and semantic content
- **CSS3** — Styling, layouts, animations and responsive design
- **React Router** — Client-side navigation and multiple-page routing
